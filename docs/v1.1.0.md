**WeRead Notes Import** adds a Logseq command and slash menu entry for the existing macOS importer. Tested with Logseq Desktop 2.0.2 DB graphs.

Start the bundled local helper, open **微信读书 · WeRead Notes Import**, and preview the books, highlights and reviews. Confirm to back up the selected graph, import the previewed snapshot and verify the records. A preview belongs to one graph and one helper session. The foreground helper exits with Ctrl-C. Existing CLI preview and import commands are still included.
